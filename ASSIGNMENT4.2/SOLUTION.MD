## ASSIGNMENT4.2

## 1. Concepts demonstrated

| HTML element or attribute | Purpose                             |
| ------------------------- | ----------------------------------- |
| `type="text"`             | Accepts the applicant's name        |
| `type="email"`            | Checks for a valid email format     |
| `type="tel"`              | Accepts a phone number              |
| `type="date"`             | Displays a date picker              |
| `type="url"`              | Accepts a website URL               |
| `type="radio"`            | Allows one preferred shift          |
| `type="checkbox"`         | Allows multiple skills              |
| `<select>` and `<option>` | Creates a dropdown                  |
| `<textarea>`              | Accepts a longer cover letter       |
| `required`                | Requires a value before submission  |
| `disabled`                | Prevents editing the Application ID |
| `<label>`                 | Gives each field an accessible name |
